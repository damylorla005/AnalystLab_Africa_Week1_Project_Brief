# AnalystLab_Africa_Week1_Project_Brief
Fintrust financial intelligence &amp; Digital Bank Support Solution

# Executive Summary

Week 1 establishes the foundation for a future machine-learning solution for FinTrust Digital Bank. The assignment asks the Machine Learning track to define a realistic predictive problem, assess the proposed Risk_Review_Flag target, identify candidate features, formulate testable hypotheses, plan the modelling workflow, identify data-quality observations, and prepare for Weeks 2–4.
The proposed direction is a supervised classification problem: use available customer and transaction information to estimate whether a transaction/customer case is associated with the synthetic Risk_Review_Flag. The prediction is intended to support risk-related review and prioritisation, not to declare fraud or make an irreversible financial decision. The assignment itself explicitly states that Risk_Review_Flag is a synthetic educational label and not a real fraud determination.
Because the Week 1 assignment brief supplied for this solution lists the approved datasets but does not contain their actual rows, numerical record counts, class balance, missing-value totals, or confirmed field values cannot responsibly be invented. Those measurements are therefore marked as items to verify when the approved CSV/XLSX resources are available.
